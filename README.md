# Обратный адрес

Камерный браузерный хоррор в духе найденной игры конца 90-х. Ночная архивариус получает дело о доме, которого нет на городской карте, и постепенно узнаёт, почему у этого дома появился нулевой адрес.

Пять связанных пространств одного здания; история раскрывается через карточки, письма, голоса жильцов и изменения знакомого коридора. В прохождении есть загадка наблюдения, сверка документов, соединение телефонной линии и ритм труб. Финальный выбор и полнота найденных свидетельств меняют одну из трёх концовок.

## Запуск

Открой `index.html` в современном браузере. Сборка, сервер, сторонние библиотеки и внешние аудиофайлы не нужны.

Звук запускается только после нажатия игроком «ЗВУК» — так браузер разрешает Web Audio. Громкость настраивается в меню паузы.

## Управление

- **WASD** или **стрелки** — движение.
- **E** или **Пробел** — осмотреть предмет рядом.
- **Escape** — пауза, громкость и перезапуск.
- **⛶** — включить или выключить полноэкранный режим.
- Можно щёлкнуть по предмету в кадре.

Прогресс сохраняется локально в браузере. После перезагрузки игра продолжится; звук потребуется включить снова.

## GitHub Pages

В репозитории есть workflow публикации. В **Settings → Pages** выбери источник **GitHub Actions**; после этого push в `main` публикует игру по адресу [saneck201-cpu.github.io/last_signal](https://saneck201-cpu.github.io/last_signal/).
