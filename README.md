# Последний свет

Новая версия браузерной пиксельной игры на русском языке. После Долгой Ночи Лена идёт через пустой северный город к радиовышке, чтобы решить, что делать с последней записью голоса брата.

История проходит через пять локаций: квартира, двор, метро, школа и радиовышка. Осматривай вещи, собирай обрывки прошлого, запусти генератор и выбери одну из трёх концовок.

## Как запустить

Открой `index.html` в современном браузере или играй на GitHub Pages: https://saneck201-cpu.github.io/last_signal/

Установка и сборка не требуются. Звук выключен до нажатия кнопки «ЗВУК» — это ограничение браузеров для автоматического воспроизведения.

## Управление

- **WASD** или **стрелки** — ходить.
- **E** или **Пробел** — осмотреть объект рядом.
- **Escape** — открыть паузу или закрыть текст.
- **⛶ ЭКРАН** — полноэкранный режим.
- Можно щёлкнуть по объекту на сцене, чтобы подойти к нему или осмотреть.

Прогресс сохраняется в локальном хранилище браузера. Игра, графика и синтезированная музыка находятся в одном файле `index.html`; внешние библиотеки и аудиофайлы не нужны.
