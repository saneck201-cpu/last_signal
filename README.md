# Последний свет

Браузерная пиксельная история на русском языке о Лене, которая идёт через пустой северный город к радиовышке, чтобы решить, что делать с последней записью голоса брата.

Пять глав: квартира, двор, метро, школа и радиовышка. Исследуй места, собирай следы прошлого, запускай генератор и настраивай передатчик. В финале выбери одну из трёх концовок.

## Запуск

Открой `index.html` в современном браузере. Сборка и установка зависимостей не нужны. Чтобы опубликовать игру в интернете, включи GitHub Pages для ветки `main`, корневой папки репозитория.

Звук выключен до нажатия кнопки «ЗВУК», потому что браузеры запрещают автоматическое воспроизведение. Музыка и эмбиент создаются в браузере, аудиофайлы не нужны.

## Управление

- **WASD** или **стрелки** — движение.
- **E** или **Пробел** — осмотреть объект рядом.
- **Escape** — пауза или закрытие окна.
- **⛶ ЭКРАН** — полноэкранный режим.
- Щёлкни по объекту на сцене, чтобы подойти или осмотреть его.

Прогресс сохраняется в этом браузере. Кнопка «СНАЧАЛА» начинает новую игру. Весь код, графика и звуковой движок находятся в одном файле `index.html`; внешние библиотеки не используются.
